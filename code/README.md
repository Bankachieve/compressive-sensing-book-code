# รหัสต้นฉบับประกอบหนังสือ "การรับรู้เชิงบีบอัด: ทฤษฎี ขั้นตอนวิธี และการประยุกต์ทางวิศวกรรมไฟฟ้า"

รหัสในโฟลเดอร์นี้สร้างภาพผลการคำนวณและค่าตัวเลขทุกค่าที่อ้างในเนื้อหาและคำบรรยายภาพ
(ยกเว้นค่าที่ระบุว่ารายงานจากบทความต้นฉบับ และแผนภาพเชิงแนวคิดที่วาดด้วย TikZ)

## การติดตั้ง
1. ติดตั้ง Python 3.11 ขึ้นไป (ผลในเล่มได้จาก Python 3.13)
2. ในโฟลเดอร์ `code/` รัน `python -m pip install -r requirements.txt`

## การรัน
- ภาพบันทึกลงโฟลเดอร์ `figures/` ที่อยู่ถัดจาก `code/` ค่าตัวเลขพิมพ์ออกทางหน้าจอ
- ตำแหน่งไฟล์กำหนดเทียบกับตัวสคริปต์ จึงรันจากโฟลเดอร์ใดก็ได้
- ผลทั้งหมดในเล่มรันบน Linux ส่วน macOS และ Windows ใช้รหัสเดียวกันได้ (`fig06_generate.py` ล็อกไฟล์ด้วย `fcntl` บน POSIX และ `msvcrt` บน Windows) แต่ยังมิได้ทดสอบบนสองระบบหลัง
- สคริปต์บทที่ 4–8 เลือกรันเฉพาะส่วนได้ ถ้าไม่ระบุชื่อส่วนจะรันทุกส่วน เช่น `python fig05_generate.py noisy amp`

### เวลาในการรัน (โดยประมาณ บนเครื่องที่ใช้จัดทำหนังสือ)
บทที่ 1–3 ไม่กี่วินาทีถึงไม่กี่นาที บทที่ 4–5 หลายนาที
ส่วน `mri` `irls` และ `optical` ของบทที่ 6 และ `gridless` `pnp` `unroll` ของบทที่ 8 ใช้เวลาหลายสิบนาทีถึงหลายชั่วโมง
ส่วน `optical` ของบทที่ 6 วาดภาพจากผลที่บันทึกไว้ใน `logs/fig06_optical_results.json` และ `logs/fig06_optical_cassi_recs.npz` ได้โดยไม่ต้องคำนวณใหม่

## การเทียบผล
โฟลเดอร์ `logs/` เก็บผลที่พิมพ์ออกจากการรันที่ใช้จัดทำหนังสือ (`fig0N_<ส่วน>.log`) ใช้เทียบกับผลที่ได้บนเครื่องของผู้อ่าน
ค่าเริ่มต้นของตัวสร้างเลขสุ่มกำหนดคงที่ทุกไฟล์ ผลด้านความแม่นยำจึงทำซ้ำได้
เวลาคำนวณและตัวเลขหลักท้าย ๆ ของค่าที่ใกล้ศูนย์มาก (เช่น 1e-15) ขึ้นกับเครื่องและเวอร์ชันของไลบรารี
ไฟล์ที่ลงท้ายด้วย `_old.log` คือผลของการตั้งค่าเดิมก่อนปรับให้ลู่เข้าเต็มที่ เก็บไว้เพื่อการตรวจสอบย้อนหลัง

## ขอบเขตของการทำซ้ำ
ค่าในตารางที่ระบุว่า "ข้อมูลจากบทความของผู้แต่ง" หรือ "เรียบเรียงจาก" บทความต้นฉบับ
(ตาราง IRLS-DR ในบทที่ 4, สัญญาณจากการวัดจริงในบทที่ 5, ผลที่บทความรายงานในบทที่ 7) เป็นผลของบทความนั้น ไม่ได้สร้างจากโฟลเดอร์นี้
