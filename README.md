# รหัสต้นฉบับประกอบหนังสือ "การรับรู้เชิงบีบอัด"

โค้ด Python ที่ใช้สร้างภาพและตัวเลขผลการทดลองทุกค่าในหนังสือ
"การรับรู้เชิงบีบอัด" (Compressive Sensing) โดย รศ.ดร.กฤษฎา อัศวสกุลเกียรติ มหาวิทยาลัยมหิดล

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `code/` | สคริปต์รายบท วิธีรันอยู่ใน `code/README.md` และแผนที่ภาพ/ตาราง → สคริปต์ seed log อยู่ใน `code/MANIFEST.md` |
| `logs/` | ผลลัพธ์ที่สคริปต์พิมพ์ออกเมื่อจัดทำเล่ม ใช้เทียบเมื่อรันซ้ำ |
| `figures/tikz/` | ต้นฉบับ TikZ ของแผนภาพเชิงแนวคิด |

## เริ่มต้นใช้งาน

```bash
pip install -r code/requirements.txt
python code/fig05_generate.py omp-trace recovery
```
