## หมายเหตุ

- log ส่วน `author` ของ `fig05_generate.py` ที่รันก่อนรอบนี้ยังพิมพ์ป้าย "unit-norm columns" ตัวเลขไม่เปลี่ยน เพราะ C05 แก้เฉพาะคำอธิบาย (เมทริกซ์มีพลังงานคาดหมายของสดมภ์เป็นหนึ่ง)
- การแก้ C07 (FOCUSS และ TSVD-FNR เมื่อ y = 0) และ C04 (`hard_k` เมื่อ k = 0) กระทบเฉพาะกรณีขอบ ไม่มีการทดลองในเล่มที่ใช้กรณีเหล่านั้น
- E03: การรันซ้ำของผู้ตรวจได้ PSNR อาดามาร์ที่ m/n = 0.1 เท่ากับ 10.10 dB เทียบกับ 10.23 dB ใน log เดิม สาเหตุยังไม่ยืนยัน เล่มระบุทั้งสองค่าแล้ว
