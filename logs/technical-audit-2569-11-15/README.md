## E01 และ E03 (16 พ.ย. 2569)

- E01 (`fig04_metric_check-2569-11-15.log`): ภายใต้สมการ (26) ของบทความ JAIT 2023 และความคลาดเคลื่อนบรรทัดฐานแบบโฟรเบนิอุสบนภาพ 8 บิตเดียวกัน
  PSNR + 20 log10(nerr) = 20 log10(255/RMS(X0)) ต้องคงที่และไม่ติดลบ แต่ตารางให้ 8.17, 2.58, -0.75, -0.74 dB (RMS โดยนัย 99.6 ถึง 278 > 255)
  การจำลองขนาดเล็ก (ภาพ 48x44, M/N = 0.5, ฐาน DCT) ให้ค่าคงที่ 4.81 dB ทุกขั้นตอนวิธีเมื่อใช้โฟรเบนิอุส, 5.54/4.83/4.84 เมื่อ clip ภาพ (ไม่ติดลบ)
  และ 1.29/-4.84/-4.51 เมื่อความคลาดเคลื่อนบรรทัดฐานใช้ numpy.linalg.norm(·, 2) บนอาร์เรย์สองมิติ (นอร์มเชิงสเปกตรัม) ซึ่งให้รูปแบบเดียวกับตาราง
  คำบรรยายตาราง 4.3 แก้ตามนี้ ผู้แต่งควรยืนยันจากโค้ดต้นฉบับของบทความ
- E03 (`fig06_optical_uniqueness-2569-11-15.log`): อาดามาร์ m/n = 0.1 ครั้งที่ 1 และ 2 มีผลเฉลยเดียว (PSNR 11.74, 9.44 จากตัวแก้ทุกแบบ)
  ครั้งที่ 3 มีเซตผลเฉลยเหมาะที่สุดไม่เป็นหนึ่งเดียว: HiGHS-IPM 10.00, HiGHS dual simplex 9.93, Clarabel 16.38 dB ที่ค่า l1 เท่ากัน (ต่างกันไม่เกิน 2e-8 สัมพัทธ์)
  จุดยอดตามทิศ <c, c_true> ให้ 9.27 ถึง 11.04 dB, ผลเฉลยนอร์ม l2 น้อยที่สุดในเซตเกือบเหมาะที่สุด 16.84 dB, ดีที่สุด 17.42 dB
  ค่า 9.53 (log เดิม), 9.11 (ผู้ตรวจ) และ 10.00 (รอบนี้) จึงเป็นจุดยอดต่างกันที่ตัวแก้ต่างรุ่นเลือก ไม่ใช่ความผิดพลาด
  ค่าเฉลี่ยสามครั้งอยู่ในช่วง 10.1 ถึง 10.4 dB และไม่เกิน 12.9 dB แม้เลือกผลเฉลยที่ดีที่สุด จึงยังต่ำกว่าแบร์นูลลี (16.6 dB) บทที่ 6 แก้ตามนี้
